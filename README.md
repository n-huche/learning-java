# Learning Java

Pequenos projetos feito para aprender e praticar Java.

## Mad Libs

Jogo de escolher palavras especificas sem contexto e no fim ver uma história usando essas palavras.

### Como usar

1. Abra o diretório `mad-libs/`
2. Vá em `src/`
3. Entre em `Main.java`
4. Aperte o botão Run
5. Escolha suas palavras
